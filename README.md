# global_temblors

Global_temblors is an earthquake map based on an exercise found in "Python Crash Course" by Eric Matthes and earthquake data from the U.S. Geological Survey. The map uses Python3 and Plotly to display the name, magnitude, time (Pacific LA), location, depth, and tsunami status earthquakes occuring over the past day. <br>
